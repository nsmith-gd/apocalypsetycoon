The pacing harness now checks the GDD's cadence rules. It replays simulated campaigns (3 player styles × 3 seeds, on the same systems the game runs) and lists every violation with its campaign time. The command is `node tools/pacing-harness.mjs --cadence`. It prints PASS or FAIL per rule and exits non-zero on any violation, so the CI ticket can run it as is. Add `--bot edge --seed 1` for one run in full, or `--out <dir>` to write a JSON copy.
