## Questions
### Is a save only at quarter starts too strict for a five-hour game?
Context: The game now saves only at the start of each quarter, about every 30 minutes of play. If you quit mid-quarter, Continue brings you back to the start of that quarter, and the last few minutes are replayed. That keeps the save simple and always consistent, but you can lose up to half an hour.
Options: - Quarter starts only (current): one clean checkpoint, nothing half-finished
- Also save when quitting to the menu: nothing lost, but you resume mid-quarter
- Also autosave every in-game month (4 weeks): at most about 9 minutes lost
Going with: Quarter starts only, because the ticket defines the checkpoint that way and it guarantees an identical restore.
